# Nucleus Blog Content

Blog post content for nucleushq.co.uk. Committing here does **not** trigger a Netlify deployment.

## Adding a new post

1. Write your post as `your-post-slug.md` in this folder
2. Add an entry to `posts.json` with `"url": "post.html?slug=your-post-slug"`
3. Commit and push — live immediately, zero Netlify deploys
